# Notebooks

Jupyter notebooks (`.ipynb`) are messy in Git: just running one changes the file,
and two people editing the same notebook almost always ends in an unfixable merge conflict.

**Rules:**

- Notebooks here are **personal scratch space** for experiments.
- Name yours `yourname-topic.ipynb` (for example `priya-data-cleaning.ipynb`).
- **Never edit someone else's notebook.**
- When code works, move it into a `.py` file in the project. That's the real code.
